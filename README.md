# Layout Fixer – fix text typed in the wrong keyboard layout (Windows)

[![Get it from Microsoft Store](https://get.microsoft.com/images/en-us%20dark.svg)](https://apps.microsoft.com/detail/9N32C01ML8D1)

**Layout Fixer** (Microsoft Store: *Layout Fixer – Arabic English*, Store ID `9N32C01ML8D1`, US$1.99, v1.1) is a Windows 10/11 tray app
that fixes text typed in the wrong keyboard layout. Select the garbled text in almost any app and press **Ctrl+Shift+L** (configurable):
the app detects which layout the text was typed in, remaps every character to the one on the same physical key in the other layout,
and pastes the result over the selection.

| You typed | Becomes | Layouts |
|---|---|---|
| `ghbdtn` | привет | English (US) → Russian |
| `ghbdsn` | привіт | English (US) → Ukrainian |
| `hgsghl ugd;l` | السلام عليكم | English (US) → Arabic (101) |
| `akuo` | שלום | English (US) → Hebrew |
| `sghl` | سلام | English (US) → Persian |
| `kwrdy` | کوردی | English (US) → Central Kurdish |
| `kalhm;era` | καλημέρα | English (US) → Greek |
| `g]zel` | güzel | English (US) → Turkish Q |
| `руддщ цщкдв` | hello world | Russian → English (US), auto-detected |

- Any pair of the supported layouts (not only to/from English); defaults come from the layouts installed in Windows.
- Auto-detects the direction (or force one); optional clipboard-only mode; optional switch of the active layout after fixing.
- UI in 15 languages (ar, de, el, en, es, fa, fr, he, hi, ckb, pt-BR, ru, th, tr, uk) with RTL support.
- Fully offline: no telemetry, ads or accounts ([privacy policy](https://murtadhaqahtan.github.io/layout-fixer-site/privacy.html)).
- Not a translator (`ghbdtn` → привет, not "hello"), and it never watches typing — it only acts when you press the hotkey.
- Limitations: AltGr characters aren't mapped; digits are kept as typed; Hindi and Thai are UI languages only (no layout conversion);
  Windows only (10 1809+ / 11, x64 and ARM64).

## Supported layouts (1.1)
| id | Windows layout | KLID | Source DLL |
|---|---|---|---|
| `us` | US | 00000409 | kbdus.dll |
| `ar-101` | Arabic (101) | 00000401 | kbda1.dll (table frozen from 1.0 for byte-for-byte compatibility) |
| `fa` | Persian | 00000429 | kbdfa.dll |
| `fa-std` | Persian (Standard) | 00050429 | kbdfar.dll |
| `ckb` | Central Kurdish | 00000492 | kbdkurd.dll |
| `he` | Hebrew | 0000040D | kbdheb.dll |
| `he-std` | Hebrew (Standard) | 0002040D | kbdhebl3.dll |
| `ru` | Russian | 00000419 | kbdru.dll |
| `uk` | Ukrainian | 00000422 | kbdur.dll |
| `el` | Greek | 00000408 | kbdhe.dll |
| `tr-q` | Turkish Q | 0000041F | kbdtuq.dll |

Tables are generated by `tools/klc2json.py` from the KLC files in `tools/klc/`, which kbdlayout.info derives from the
`KBDTABLES` compiled into each Microsoft layout DLL (DLL version noted in each file header and in the table's `source` field).
Unshifted + Shift states are mapped; dead keys (Greek tonos/dialytika, Turkish ^) compose/decompose; ligatures (Persian ریال, Kurdish وو) expand.
Digits are always kept as typed (Persian/Kurdish number rows produce native digits, which would otherwise change numbers).

## Features
- Global hotkey (RegisterHotKey) converts the selection (simulated Ctrl+C / Ctrl+V, clipboard restored) or just the clipboard
- Layout pair chosen from the user's installed Windows layouts (HKCU\Keyboard Layout\Preload); any pair can be picked in Settings.
  Upgrades from 1.0 keep US/Arabic.
- Auto-detect direction: counts letters only one of the two layouts can produce (script/letter evidence); if the text belongs to another
  installed supported layout instead, it is converted from that one. Or force a direction.
- Optional switch of the active keyboard layout after fixing (only to installed layouts)
- Tray icon + settings window; UI in 15 languages (`the app`), follows the Windows display language
  with a manual override; RTL for Arabic, Persian, Hebrew, Kurdish. MSIX display name/description localized via `Strings/<lang>/Resources.resw`
  (`python3 tools/gen_resw.py`).
- Run at startup via MSIX `StartupTask`
- Offline, no telemetry ([privacy policy](docs/PRIVACY.md))

## Known mapping notes
- AltGr layers are not mapped (e.g. Ukrainian ґ is only on AltGr+U / the ISO-only key 56, so it stays as is).
- Key `B` and keys `G`+`H` both produce `لا`; Arabic→English yields `gh` (more common in English words).
- `لأ لإ لآ` decompose to `gH`, `gY`, `gN`.
